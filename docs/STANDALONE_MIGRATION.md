# Standalone Migration Notes

This repository was split out of the former `smallGames-main/games/human-protocol` workspace so the game can build and run without the surrounding monorepo.

## Included

- Game source, builder source, UI, Raw WebGPU renderer, tests, and QA scripts.
- Runtime assets under `src/assets` and `public/assets`.
- Blender and procedural asset scripts under `scripts/asset-build`.
- Source `.blend` files under `src/assets/source_blend`.
- Working reference and scripted-derived asset folders under `work`.
- The local `@age/render-webgpu` source package under `packages/age-render-webgpu`.
- Human Protocol Codex skill handoff docs under `docs/codex-skills`.

## Intentionally Excluded

- `node_modules`: regenerated with `npm install`.
- `dist`: regenerated with `npm run build`.
- `.tmp` and `tmp`: local screenshots, dev-server logs, experiments, and generated scratch files.
- Zip/log files and local AI training exports ignored by `.gitignore`.
- `src/assets/manifests/generated/raw-webgpu/render_plan_builder_runtime_resources_geometry.bin`: a generated builder-runtime aggregate geometry file over GitHub's 100MB single-file limit. The game keeps the split Raw WebGPU packs in `public/assets/human-protocol/raw-webgpu`, and the aggregate can be regenerated by the asset pipeline.

## Main Commands

```bash
npm install
npm run dev
npm run build
npm run qa:builder
npm run raw-webgpu:rebuild:all
```

Blender pipeline scripts assume Blender is available at `/Applications/Blender.app/Contents/MacOS/Blender` or `/Applications/Blender.app/Contents/MacOS/blender`, matching the existing package scripts.
