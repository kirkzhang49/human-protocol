1. Run `npm run qa:playthrough`.
2. Confirm level 1 reaches elevator after picking both story weapons and clearing combat.
3. Confirm level 2 boss key, locked room, lamp sequence, and exit all resolve.
4. Confirm level 3 entry, chips, body sequence, curator fight, and exit all resolve.
5. Confirm level 4 room completions, theater door, therapist fight, and exit all resolve.
6. Confirm level 5 north puzzle, three keys, platform door, final boss, and identity file all resolve.
7. Run `npm run smoke:campaign`.
8. Run `npm run build`.
9. Run `git diff --check`.
10. If UI changed, verify with Browser on local dev server.
