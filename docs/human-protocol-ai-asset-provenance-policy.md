# AI Asset Provenance & License Policy (Human Protocol)

> **中文摘要（先看这个）**
> 以后**任何 AI 生成的素材**（Image2 贴图/图像、Suno 音乐、AI 渲染、未来的 AI 3D 等）在**生成的当下就必须留证据**，否则不许进游戏、不许上线。
> 「证据」= 三样东西，缺一不可：① **来源**（什么工具+版本、什么账号、生成日期、用的 prompt）；② **商用权凭证**（生成当时该工具的条款截图/链接，能证明允许商用 + 游戏再分发）；③ **源文件存进仓库**（不能只躺在 `~/.codex/` 或某台机器上）。
> 然后在 `docs/asset-license-ledger.md` 台账里登记一行。
> 现在这套 Image2 不一定最终用，**所以不必逐个补全旧的**——但凡是**确定要进正式版**的那批，上线前必须按本政策补齐 + 把下面「已知缺口」清掉。

---

## 1. Why this exists

Steam (and itch / CrazyGames / direct sale) require, at submission, an **AI Content Disclosure**: the developer must declare which assets are AI-generated and **attest they hold the rights to use them**. The real legal exposure is not Steam rejecting the build — it is:

1. **Commercial-use rights from the generating tool.** Many AI tools grant commercial rights only on certain plans / terms, and terms change over time. Example already in this repo: Suno's free tier does **not** grant commercial rights (see `src/assets/audio/licenses/last-human-bay.md`, status *"pending verification"*).
2. **Copyrightability.** Purely AI-generated images may not be copyrightable in some jurisdictions (e.g. US Copyright Office guidance), meaning we may be unable to stop others copying them. Usually acceptable for a game, but worth knowing.

Provenance must be captured **at generation time**, because the tool's terms, the account, and the export proof are hard or impossible to reconstruct later.

## 2. Scope

Applies to **every AI-generated asset**, including but not limited to:

- **Image2 texture atlases & images** — AI image generation (the `*image2*` / `*-sources` pipeline, the `museum-wall-art` murals, hero floors, furniture/door/puzzle textures, GUI art).
- **Audio** — Suno or any AI music/SFX (already partially covered under `src/assets/audio/licenses/`).
- **AI-rendered / AI-upscaled / AI-inpainted** derivatives.
- **Future AI 3D / animation** assets.

**Out of scope** (no AI-license record needed, but keep normal source notes):
- **CC0 third-party assets** (ambientCG textures, Poly Haven GLBs) — commercial-safe, attribution not required. *Still record the source URL + "CC0" in the ledger for our own defense.*
- **Procedural / self-authored geometry** (Blender scripts in `scripts/asset-build/`) — fully owned; provenance is the script itself.
- **Config / layout data** generated by a local LLM — data, not copyrightable art.

## 3. The rule (mandatory, at generation time)

Before an AI-generated asset may be **committed for runtime use**, ALL of the following must exist:

1. **A ledger row** in `docs/asset-license-ledger.md` (see template §6).
2. **The generated source file archived inside the repo** under `src/assets/<area>/<...>-sources/` (or `provenance/`) — **never** left only in a machine-local path such as `~/.codex/generated_images/...`. If the source is large, archive it in the repo's asset store / LFS, not only on one laptop.
3. **Commercial-rights proof archived**: a snapshot (PDF/PNG) or permalink of the tool's terms **at the generation date** showing commercial use + redistribution-in-a-game are permitted, plus the account/owner and the export/track id.

If any of the three is missing, the asset's status is **`unverified`** and it must not ship in a commercial release.

## 4. Required provenance fields (per asset)

| Field | Example |
|---|---|
| `asset` (runtime path) | `src/assets/textures/environment/level06-10-hero/hero-console-01.webp` |
| `origin` | `ai-image` \| `ai-audio` \| `cc0` \| `procedural` \| `human` |
| `tool` + version | `OpenAI Codex image-gen` / `Suno v4` / `ambientCG` / `Blender blender-build-prop.py` |
| `account` | who owns the generating account |
| `date` | generation date (UTC) |
| `prompt` / source ref | prompt text or source URL (for CC0) |
| `source_file` (in-repo) | `src/assets/.../*-sources/<original>.png` |
| `commercial_status` | `cleared` \| `unverified` \| `cc0` \| `owned` |
| `proof` | path/URL to archived ToS snapshot + export proof |
| `notes` | e.g. "no readable text/logos/named IP in prompt" |

## 5. Prompt rules for AI generation (keep us clean)

Mirror the constraints already used in `src/assets/environment/README.md` and the Suno license notes:

- **No** named artists, named songs/films/game OSTs, copyrighted melodies/lyrics, franchise names, real logos, watermarks, or recognizable characters/celebrities.
- Generate **reusable, text-free, UV-friendly** production assets (atlases/trims), not scene screenshots or anything resembling a specific commercial IP.
- Keep a **non-AI fallback** available where practical (e.g. procedural Web-Audio SFX, procedural textures) so the game can ship if a tool's licensing changes.

## 6. Ledger row template

Add to `docs/asset-license-ledger.md`:

```
| asset | origin | tool@ver | account | date | source_file (in-repo) | commercial_status | proof | notes |
|-------|--------|----------|---------|------|-----------------------|-------------------|-------|-------|
| src/assets/.../foo.webp | ai-image | codex-image | <acct> | 2026-06-14 | src/assets/.../foo-sources/foo.png | unverified | docs/provenance/foo-tos.png | text-free, no IP |
```

## 7. Pre-ship checklist (per asset, before a commercial release)

- [ ] Asset is in the ledger.
- [ ] Source file archived **in the repo** (not only `~/.codex/` or a laptop).
- [ ] Tool's commercial + redistribution terms **at generation date** archived as proof.
- [ ] `commercial_status` flipped from `unverified` → `cleared` / `cc0` / `owned`.
- [ ] Prompt rules (§5) confirmed — no IP / named refs / readable logos.
- [ ] Listed in the Steam **AI Content Disclosure** inventory.
