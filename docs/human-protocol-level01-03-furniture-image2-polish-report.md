## 1. Audit table (pre-polish baseline)

Columns: **size** = GLB bounds W×H×D (m). **groundY** = lowest vertex Y; `0`
means base sits on the floor, negative means the pivot is at the vertical
centre so the engine (which places props with the GLB origin at floor Y, no
auto-grounding) sinks the model. **tex** = materials with `baseColorTexture` /
total materials. **verts** = vertex count. Issue flags use the quality gates:
G=grounding, T=texture-visible, V=volume/bevel, P=in-engine proof.

## 2. Fixes applied

All three generators were edited (modelKeys, manifest packIds, atlas paths, and
`/build` wiring unchanged). GLBs regenerated, registry re-emitted, WGPU resource
pack re-cooked, thumbnails regenerated.

### Level 01 (`generate-level01-furniture-image2-assets.py`, Blender)
- Added `ground_root()`: evaluates world-space Z extent via the depsgraph and
  shifts the root so `minZ → 0` (floor mode) or `maxZ → 0` (ceiling mode), then
  **applies all transforms** so the baked GLB POSITION accessor reflects grounded
  world bounds. Previously the models were centre-pivoted.
- Result: all 7 floor-standing models now `groundY = 0`; the ceiling service
  light uses `mode="ceiling"` (top plate at Y=0, hangs 0.225 m down).
- Texture coverage preserved (5–8 textured atlas materials/model: brushed steel,
  cyan lens, amber fault, hazard edge, diagnostic screen). Existing bevels kept.
- Manifest `sizeMeters` updated to **true grounded heights** (see risk 1).

### Level 02 (`generate-level02-furniture-image2-assets.py`, trimesh)
- Root cause: only the small `inlay` panels carried a textured `PBRMaterial`; all
  bulk parts used flat `ColorVisuals`. Now **every named material slot gets its
  own `PBRMaterial` with a painted `baseColorTexture`** (laminate grain, cream
  upholstery, beige plastic w/ seams+screws, brushed brass, warm glass, cyan
  scanner, camera lens, wallpaper, service panel), and body parts are built with
  full-UV `face_box()` so the tile reads on all visible faces.
- Added `bevel_box` volume to plinths, seat/back cushions, arms, posts, carcass;
  kept cyan scanner seams + a hidden camera/scanner lens detail per piece.
- Result: `texturedCount` went **1/N → N/N on all 8** (min 7/7), still `groundY=0`,
  every GLB ≤ 330 KB.

### Level 03 (`generate-level03-furniture-image2-assets.py`, trimesh)
- Root cause for grounding: `finalize()` used `scene.apply_translation()`, which
  moves node matrices only — GLB accessor min/max comes from local vertex
  positions, so the grounding never baked. Added `_apply_vertex_translation()`
  (bakes the shift into `geom.vertices`) and `finalize_wall()` for wall mounts.
- 4 floor pieces re-grounded to `groundY = 0` (label_terminal, specimen_bench,
  preservation_case; mural_lightbox kept as a wall pivot at `-0.55`).
- Added real volume so pieces read as 3-D, not atlas cards: vitrine glass + brass
  corner posts + amber glow rings (preservation_case), cross stretchers + back
  rail (specimen_bench), thicker head + base plate (label_terminal), deeper box +
  rivets + wall brackets (mural_lightbox). Material slots (enamel/brass/smoked
  glass/amber) all preserved at N/N textured.

## 3. Remaining risks

1. **Level 01 `sizeMeters` changed substantially** (e.g. repair_workbench
   0.72→1.25, battery_cart 0.42→0.925). These were *under-measured* before — the
   original audit read local accessor bounds and ignored per-node translations,
   so multi-node Blender models reported only part of their true height. The
   manifest now has accurate grounded bounds and the registry/footprints were
   re-emitted, but any hand-authored config using the old collision sizes should
   be re-checked. (Builder footprints regenerate from the manifest automatically.)
2. **Level 02 vertex counts stay lean** (192–560). Bevels add some volume but
   sub-0.5 m inspection still reads simple; the surface read now comes from real
   `baseColorTexture` rather than geometry. Acceptable for filler furniture.
3. **`mural_lightbox` groundY = -0.55 is intentional** (wall pivot, `mount:"wall"`,
   `wallPreferred:"back"`). The runtime must place it at wall height (~1.1–1.4 m);
   if it floors it to 0 the box sits too low.
4. **Agent contact-sheet renders** used numpy/matplotlib (no PBR/texture
   sampling), so those prove geometry + grounding only. The **texture-visible**
   proof is (a) the GLB texture audit (`baseColorTexture` N/N — section 4), and
   (b) the regenerated `/build` thumbnails, which are real WebGPU in-engine
   renders through the material path.
5. `camera_lamp` warm-glass emissive is subtle; keep emissive intensities ≤ 1.0
   per channel to avoid bloom wash-out.
