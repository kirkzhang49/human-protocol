# Human Protocol Next Design

本文件继续设计原 `Mech Survivor 3D` 概念当前演进后的方向：`Human Protocol`。目标不是重写已有第一关，而是把现在已经能玩的 demo 推成一个让玩家愿意重打一局、比较一局、解锁下一段真相的产品原型。

## 1. 当前判断

现在的游戏已经有一个清楚的钩子：

> 玩家以为自己是最后的人类，在维修舱里被机器人围攻；实际这些“敌人”是维修/回收系统，玩家可能只是一个相信自己是人类的维修对象。

当前第一关已经具备：

- mobile-first 第一人称移动、自动开火、锁定锥和威胁环。
- `实验铁棒 / 实验手枪 / 核心大招` 三技能身份。
- 波次、三选一升级、正常 HP 归零死亡、复活超频、出口胜利。
- Memory fragments、Memory Cache、连杀、Build 名称和胜利比较。
- 前 90 秒基础美术、中文任务提示和平台打包流程。

最大缺口也很明确：

- Memory 是局内奖励，还不是跨局动机。
- 第一关自动化通关约 80-97 秒，和 3-5 分钟目标仍有距离。
- 敌人还不够强迫玩家判断“现在该用棒、枪还是大招”。
- 死亡/胜利后还缺一句让玩家知道“下一局怎么打得更好”的诊断。

设计目标：先把第一关变成一个可重玩的 5-10 分钟试玩闭环，再考虑新关卡和更重资产。

## 2. 产品支柱

### 两拇指机甲幸存者

手机玩家不做精准 FPS 瞄准。玩家负责移动、转向、技能选择和升级选择；系统负责自动开火、轻辅助瞄准、威胁方向提示和读招提示。

验收标准：

- 首次击杀在 15 秒内。
- 玩家在 1 分钟内自然理解铁棒是主输出。
- 玩家在 3 分钟内至少主动切换一次手枪或大招。

### 人类错觉反转

机器人不是“邪恶敌人”，而是用维修逻辑处理玩家。HUD 的敌意来自误译，真实标签逐步显露。

验收标准：

- 首局胜利页必须让玩家明确知道：自己不是普通人类。
- Prototype 升级、Memory Lab、敌人名字都围绕“维修对象/认知层/记忆文件”展开。

### Memory 是真相经济

Memory 不只是分数。它要同时是：

- 局内 Cache 成长。
- 跨局解锁货币。
- 档案收集进度。
- 下一局开局差异来源。

验收标准：

- 首局结束 10 秒内，玩家能花掉一次 Memory 或解锁一个档案。
- 胜利页不只给 `Replay`，还给一个明确的 `解码记忆` 动作。

### 三技能互相需要

铁棒、手枪、大招不是三把 DPS 不同的枪，而是三种问题的答案。

- 铁棒：近身主伤害、连杀、热量返还。
- 手枪：远处牵制、护盾打断、精英弱点、炮台。
- 大招：被包围、回血路线、清场和剧情揭示。

验收标准：

- 至少 3 种敌人分别偏向三种技能解决。
- 如果玩家只用一个技能，仍能过，但更慢、更危险、Memory 更少。

## 3. 前 10 分钟体验

### 0:00-0:20 唤醒和第一砸

只教一件事：你醒了，机器人靠近，你用铁棒砸碎第一个维修无人机。

设计要点：

- 第一只 `repair_drone` 靠近但伤害低。
- 铁棒命中要有重击音、短顿帧、火花和 Memory 吸入。
- HUD 仍误报 `Hostile unit detected`。

### 0:20-1:30 正面维修小队

教移动、自动锁定、热量和 Memory。

敌人：

- `repair_drone` 为主。
- 少量 `shield_tech` 只做视觉预告，不立刻惩罚新手。

奖励：

- 第一波结束给第一次三选一。
- 左一继续优先火力路线，保证选完马上变强。

### 1:30-3:00 威胁环和手枪理由

侧后方 `clamp_bot` 出现，威胁环亮起。加入一个必须用手枪更舒服解决的远程或护盾窗口。

关键设计：

- `clamp_bot` 逼近速度高，贴脸后适合铁棒清。
- `shield_tech` 展开护盾时，铁棒和大招效率下降，手枪命中弱点可打断。
- UI 用短提示，不写教程长文。

### 3:00-4:30 第二次升级和误译线索

升级后 Build 名称必须变成玩家能记住的身份：

- `铁棒手枪`
- `近身大招流`
- `火力清场`
- `核心坦克`
- `人类认知层`

这里插入一句维修真实语气，再由 HUD 误译成敌意。

### 4:30-6:30 维修主管和 Identity Crash

`custodian_elite` 让玩家感到“快赢了”，但不能定时抢走控制权；死亡必须来自正常 HP 归零。

节奏：

- 先让玩家打掉一段 HP 或清完一批增援。
- 低血量预警，而不是定时剧情死亡。
- HP 归零后进入紧急维修死亡面板。
- 死亡面板解释维修系统接管，复活保留 Memory。

### 6:30-7:30 复活反杀

复活不是续命，而是高光：

- 70% HP。
- +12 Memory。
- 9.5 秒超频。
- 身边维修机器人震开或击杀。
- 大招冷却重置。

关卡应安排一小段“被包围 -> 复活震开 -> 反推维修主管”的固定体验。

### 7:30-8:30 出口追击

击败维修主管后不要只走到门。加入 20-30 秒出口追击：

- 电梯门倒计时。
- 少量低伤维修无人机追来。
- 玩家目标从“清怪”变成“冲进维修电梯”。

### 8:30-10:00 Memory Lab

首局胜利后进入 `Memory Lab`，这是下一轮最重要的新增屏幕。

玩家看到：

- 本局 Memory。
- 最佳连杀。
- 已开启 Cache。
- 一句诊断建议。
- 三个可解码节点。

首局至少能完成一个解锁，避免玩家看见一堆灰色按钮。

## 4. Memory Lab

Memory Lab 是最小跨局留存系统。第一版不要做复杂装备、背包或商店，只做 3 条解锁线。

### 4.1 三条线

#### Protocol Decoder

用途：解锁真相档案和下一关入口。

节点：

| ID | Cost | 名称 | 效果 |
| --- | ---: | --- | --- |
| `file_subject_mobile` | 20 | 对象可移动 | 解锁档案 01，胜利页显示真实标签 |
| `file_human_layer` | 55 | 人类层残留 | 下一局可见少量真实敌人名 |
| `route_transit_spine` | 110 | 运输脊柱入口 | 解锁第二关设计入口 |

#### Tool Bench

用途：给很小但可感知的永久成长。

节点：

| ID | Cost | 名称 | 效果 |
| --- | ---: | --- | --- |
| `bench_heat_sink` | 25 | 废热槽 | 开局最大热量 +5 |
| `bench_pistol_feed` | 45 | 手枪供弹轨 | 手枪换弹 -0.4 秒 |
| `bench_revival_capacitor` | 85 | 复活电容 | 复活超频 +1.5 秒 |

#### Symptom Archive

用途：下一局开局 seed，制造“这一把不一样”。

节点：

| ID | Cost | 名称 | 效果 |
| --- | ---: | --- | --- |
| `symptom_fast_reflex` | 30 | 人类反射 | 开局移动 +4%，但热量增长 +4% |
| `symptom_maintenance_leak` | 60 | 维修反射泄露 | 看到更多真实标签，但第一波多 2 个维修无人机 |
| `symptom_core_denial` | 90 | 核心否认 | 大招冷却 -6%，但 Identity Crash 预警更短 |

第一版可以先实现前 3-5 个节点，不需要全做完。

### 4.2 持久化数据结构

建议新增：

```ts
export interface MetaProgressState {
  totalMemoryEarned: number;
  spendableMemory: number;
  unlockedNodeIds: string[];
  selectedSymptomId: string | null;
  bestMemoryRun: number;
  bestKillStreak: number;
  victoryCount: number;
  seenArchiveIds: string[];
}
```

建议文件：

- `src/game/config/memoryUnlocks.ts`
- `src/game/core/MetaProgression.ts`
- `src/ui/MemoryLabOverlay.tsx`

存储方式：

- 第一版用 `localStorage`。
- 所有节点明示 cost 和效果。
- 不做隐藏概率、假稀有、付费压力。

### 4.3 胜利页改造

当前胜利页按钮是 `再打一遍第一关`。下一版应改成两个动作：

- `解码记忆`：打开 Memory Lab。
- `再打一遍`：直接 replay。

死亡页也可以显示“本局 Memory 会在胜利后带回”，但不要允许死亡直接全额消费，避免自杀刷资源。第一版可用规则：

- 胜利带回 100% Memory。
- 死亡重开带回 35% Memory；如果第一关发生死亡，必须来自 HP 归零，不做定时剧情死亡。

## 5. 敌人和技能设计

### 5.1 已有敌人的下一步行为

#### repair_drone

定位：铁棒教学对象。

下一步：

- 更明显的贴脸维修臂。
- 被铁棒击杀时给额外热量返还反馈。
- 死亡掉落 Memory 吸入线。

#### clamp_bot

定位：威胁环和铁棒贴脸对象。

下一步：

- 更强侧后方包抄。
- 接近后短暂停顿再夹持，给玩家半秒反应。
- 被铁棒横扫时更容易击退。

#### shield_tech

定位：手枪理由。

下一步：

- 每隔数秒展开护盾。
- 护盾展开时铁棒伤害降低，大招击退降低。
- 手枪命中弱点或连续命中可打断护盾，打断给 `+2 Memory` bonus。

#### signal_turret

定位：2 分钟后出现的远程读招对象。

下一步：

- 只在第一关后半或出口追击出现。
- 发射前有 1.2 秒红线预告。
- 手枪打断最舒服，大招可应急，铁棒要冒险靠近。

#### custodian_elite

定位：剧情和复活教学核心。

下一步：

- 分 3 个阶段，不靠堆血拖时间。
- 70% HP：召维修无人机，教清小怪。
- 45% HP：低血量/维修接管预警，但不触发定时死亡。
- 20% HP：打开出口追击倒计时。

### 5.2 新敌人候选

第一阶段最多选 1 个新增敌人，不要一次加太多。

| ID | 名称 | 作用 | 推荐阶段 |
| --- | --- | --- | --- |
| `triage_laser` | 分诊激光器 | 手枪打断、远程预警 | 第一关后半 |
| `anesthesia_mist` | 麻醉雾罐 | 迫使玩家离开原地 | 第二关 |
| `scrubber_mine` | 清洗地雷 | 路线选择、出口追击 | 第二关 |
| `false_rescue_drone` | 伪救援无人机 | 叙事误导、掉落诱饵 | 第一关结尾或第二关 |

## 6. 升级池扩展

下一批升级目标：让两次升级也有路线记忆；三次升级时开始形成真正 build。

### 6.1 新增升级候选

| ID | 稀有度 | 类别 | 名称 | 效果 |
| --- | --- | --- | --- | --- |
| `blade_magnetic_swing` | Rare | blade | 磁锁甩棍 | 铁棒横扫会轻拉近身敌人 |
| `blade_second_impact` | Epic | blade | 二次冲击 | 铁棒击杀后下一次铁棒追加冲击波 |
| `gun_interrupt_rounds` | Common | gun | 打断弹 | 手枪对护盾/炮台打断效率提高 |
| `gun_clean_reload` | Rare | gun | 快速供弹 | 手枪换弹更快，换弹后 2 秒射速提升 |
| `ultimate_memory_breach` | Prototype | story | 记忆破口 | 大招命中精英会显示真实台词并掉落额外 Memory |
| `assist_threat_latch` | Common | assist | 威胁锁存 | 点威胁环转身后短暂扩大锁定锥 |
| `core_cache_hunter` | Rare | core | 缓存猎手 | 每开一个 Memory Cache 给短超频 |

### 6.2 路线规则

用简单规则就能让 build 更有身份：

- 同类别 2 张：显示路线名。
- 同类别 3 张：触发路线小进化。
- 两类别各 1 张：显示混合路线。
- Prototype 只在第二次升级后出现，避免新手首选看不懂。

路线例子：

| 条件 | Build 名 | 行为变化 |
| --- | --- | --- |
| blade >= 2 | 铁棒收割 | 连杀窗口更宽，铁棒击杀反馈更亮 |
| gun >= 2 | 手枪打断 | 护盾/炮台被打断时掉额外 Memory |
| ultimate >= 2 | 核心反冲 | 大招后短暂无敌或回血 |
| blade + gun | 铁棒手枪 | 贴脸击杀后自动给手枪 reload bonus |
| blade + ultimate | 近身大招流 | 铁棒连杀缩短大招冷却 |
| gun + ultimate | 火力清场 | 手枪打断提高大招伤害 |

## 7. 死亡和胜利诊断

目标：每次失败或通关后，玩家知道下一局可以尝试什么。

第一版只做规则判断：

| 触发 | 建议文案 |
| --- | --- |
| `deathReason === combat` 且 bestKillStreak < 5 | `连杀断得早：贴脸用铁棒，5 连杀会触发超频。` |
| Memory 距下一 Cache <= 5 | `差一点开缓存：优先清小怪续连杀。` |
| 没有枪升级且出现 shield_tech | `护盾技师更怕手枪打断，下一局试试枪路线。` |
| revivesUsed === 0 且 HP 很低胜利 | `你硬撑过来了：核心装甲或大招维修会更稳。` |
| 手枪路线但击杀慢 | `手枪负责打断和弱点，不适合当主输出。` |
| 大招路线且死于包围 | `被围时先点红色威胁弧，再开大招清空间。` |

接入：

- 死亡页显示 1 条。
- 胜利页显示 1 条。
- Memory Lab 显示 1 条“下局目标”。

## 8. 第一关拉长方案

不要靠堆 30 个怪拉时长。用目标段落拉长。

### 方案 A：Lockdown Wave

在 `wave_02` 后加短波：

- 名称：`lockdown_wave`
- 时长：45-60 秒。
- 目标：打断 2 个 `signal_turret` 或 `shield_tech`，恢复电梯权限。
- 奖励：第三次升级或 Prototype 选择。

优点：可以自然加入手枪理由和第三次升级。

### 方案 B：Exit Chase

精英死亡后不立刻结束：

- 电梯门开始 25 秒倒计时。
- 小怪从后方追来。
- 玩家需要冲到出口区域并守 4 秒。

优点：开发量小，强化“逃出维修舱”目标。

### 推荐组合

先做 B，再做 A。

原因：

- Exit Chase 改动小，能立刻改善结尾。
- Lockdown Wave 会牵涉第三次升级、远程敌人和节奏重调，放下一轮更稳。

## 9. 关卡和主线文案

主线节奏按用户指定的心理曲线推进：

1. 第一关：主角以为自己是最后的人类。
2. 第二关：发现不对劲，但还能自我解释。
3. 第三关：明显可疑，玩家开始不信 HUD。
4. 第四关：主角主动找证据，不再只是逃。
5. 终局：发现自己不是人类，或者至少不是“最后的人类”这个身份。

叙事原则：

- 不要第一关就把真相讲完。第一关只给异常词：编号、对象、外壳、最后人类记录缺失。
- 每关必须有一个“玩家能复述”的恐怖发现。
- 所有对白短、硬、带压力。战斗中每句最好 8-22 个中文字符，最多 2 行。
- HUD 不再像说明书，而像一个会撒谎、会延迟、会误译的求生系统。
- 机器人对白不要像反派宣言，要像医疗/维修流程，越冷静越可怕。

### Level 01：Maintenance Bay / 维修舱

玩家认知：我是最后的人类，我要逃出维修舱。

真实信息：它们叫我“对象”和“编号”，我的名字没有出现在档案里。

玩法目标：

- 教移动、铁棒主输出、威胁环、第一次升级、正常死亡/复活、出口。
- 不揭底，只把“不对劲”埋进对白。

关键发现：

> 最后人类记录缺失；只有“对象仍在移动”。

当前第一关运行对白应使用这种压力风格：

| Trigger | Speaker | Line | UI Tone |
| --- | --- | --- | --- |
| `level_start` | 生命维持 | 苏醒完成。生命信号：1。其他人类：0。请不要回头。 | system |
| `first_enemy_seen` | 驾驶舱警报 | 前方单位接近。它没有武器，却一直念你的编号。 | threat |
| `first_enemy_killed` | 你 | 它刚才叫我什么？我没听清。 | player |
| `wave_1_complete` | 未知频道 | 对象仍把警告理解为求生。继续施压。 | reveal |
| `wave_1_complete` | 驾驶舱 | 通信被污染：他们在重复一个名字……不是你的。 | threat |
| `rear_enemy_spawned` | 近距警报 | 后方接触。它们知道你会往哪边躲。 | threat |
| `wave_2_complete` | 未知频道 | 它开始怀疑。关闭走廊，压低光照。 | reveal |
| `elite_spawned` | 维修主管 | 编号 H-0，停止逃离。你的恐惧反应正在损坏外壳。 | threat |
| `elite_hp_50` | 未知频道 | 别让它看到档案室。它还以为自己是人。 | reveal |
| `exit_unlocked` | 系统 | 电梯开了。快走。下面有人在用你的声音呼救。 | threat |
| `exit_entered` | 系统 | 记忆片段恢复：最后人类记录缺失。对象编号仍在移动。 | reveal |

胜利页文案：

- 标题：`姓名缺失`
- 正文：`档案没有写你的名字，只写着：对象仍在移动。第二关要查清谁删掉了最后人类记录。`

### Level 02：Transit Spine / 运输脊柱

玩家认知：这里不只是维修舱，整个设施都在运送“我”。

真实信息：玩家听到其他求救声，但声音和自己一模一样。

场景：

- 狭长运输通道。
- 移动平台、传送带、封闭舱门。
- 远处红线预警，手枪价值上升。
- 墙上有大量空的人形维修架，但没有尸体。

新增敌人建议：

- `triage_laser`：远程分诊激光器，手枪打断最舒服。

## 10. 对话 UI 规则

对话必须让玩家马上看到，不能像普通小 toast。当前 UI 方向：

- 位置：屏幕上方居中，移动端横屏仍保持醒目，不躲到角落。
- 样式：红色通信警报条，左侧粗红线，底部倒计时信号条。
- 层级：高于 HUD/任务提示，低于升级/死亡/胜利全屏面板。
- 文案：每条最多两行，战斗中不超过 3.2 秒。
- 语气分层：
  - `system`：冷静系统蓝色。
  - `threat`：红色警报，立即制造危险。
  - `reveal`：金色/暗红，说明真相碎片。
  - `player`：橙色，主角短反应。
- 玩家可以点击跳过，但默认足够醒目，不需要主动找。

禁用写法：

- 不写长设定。
- 不让 NPC 解说世界观。
- 不在第一关直接说“你不是人类”。
- 不让 HUD 完全可信。
