# Stingers

One-shot music flourishes. The `MusicDirector` plays these once on a state edge
and ducks the looping music bed under them. All optional — a missing file just
means no stinger fires.

Drop in (exact names):

- `exit-unlock-stinger.mp3` — exit unlocks
- `level-transition-stinger.mp3` — level transition begins
- `victory-stinger.mp3` — victory

Add a license note under `../licenses/` before shipping. See `../README.md`.
